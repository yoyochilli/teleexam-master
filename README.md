# 星辰期末高效通

> 基于中国电信星辰超级智能体（TeleAgent）的期末备考智能体

## 项目简介

“星辰期末高效通”面向大学生课件、笔记与真题零散、复习重点难以追溯的问题。用户在 TeleAgent 中上传课程资料后，智能体以资料原文为边界，建立“资料来源—考点—练习—复习行动”的证据链。

## 核心能力

- **顺着授课逻辑整理笔记**：按 PPT 页码、讲义标题或笔记原始顺序，生成“核心线索｜详细笔记｜证据”的可背诵复习文档。
- **忠于原文，资料不足即提示**：定义、公式、结论和分值必须回指资料来源；无法定位时明确标记“资料缺失”，不补写外部知识。
- **公式规范排版**：将资料中的公式以清晰的数学格式呈现，并保留 PPT 页码；无法辨认的公式标为“公式待确认”。
- **证据约束模拟测验**：只依据课件、笔记和真题生成题目、答案与评分点；每题提供可核验的命题依据。
- **错题复习闭环**：记录错因与掌握度，生成 +1、+3、+7 天主动回忆计划和二次自测。

## 如何体验

1. 下载并在 TeleAgent 中导入 [`teleexam-master-skill.zip`](./teleexam-master-skill.zip)。
2. 上传脱敏后的课程 PPTX、笔记 TXT、真题或考纲。
3. 输入：`请按课件授课顺序整理复习笔记，每条结论标注资料证据；资料不足时标记资料缺失。`
4. 使用“生成模拟测验”或“记录错题”继续完成备考闭环。

## 隐私与边界

- 仅处理用户已授权的课程资料；演示时建议使用脱敏文件。
- 不将往年真题断言为本次考试范围。
- 不把资料外的通用知识伪装为课程结论。
