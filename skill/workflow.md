# TeleAgent 编排结构

## 处理链路

```text
用户目标与附件
  ↓
资料接入：PDF / PPTX / TXT / 笔记 / 考纲 / 题目
  ↓
资料体检：可用性 / 准备度 / 最小补充项
  ↓
文档解析：平台 PDF 解析 / PPTX 页级提取 / 文本清洗
  ↓
证据块：文件名 + 页码 / 段落 / 题号
  ↓
证据图谱：来源节点 → 考点/盲区节点 → 笔记/自测/行动节点
  ↓
自主拆解：材料盘点 → 模式选择 → 子任务排序
  ↓
结构化生成：复习页 / 真题卡 / 模拟卷 / 雷达表 / 复习计划
  ↓
证据校验：术语白名单 → 三级置信度 → 资料冲突隔离 → 推导依赖 → 公式符号保真 → 确定性审计器
  ↓
复习行动：主动回忆任务与间隔复习节点
```

## TeleAgent 能力映射

| TeleAgent 能力 | 本 Skill 的使用方式 | 可观察结果 |
| --- | --- | --- |
| 多附件理解 | 同时接收课件、考纲与题目 | 输出区分各资料来源 |
| 本地文档解析 | 按页读取 PDF，按幻灯片读取 PPTX | 每条结论保留页码 |
| 任务自主拆解 | 将复合请求拆为资料盘点、整理、命题和校验 | 一次请求生成完整复习链路 |
| 结构化输出 | 使用固定 Markdown 表格与字段 | 结果可核验、可复制、可继续更新 |
| 多轮上下文 | 接收学生作答与错题记录 | 更新掌握度并生成复习节点 |
| 自主任务拆解 | 首次资料接入先做资料体检，再选择最短复习路径 | 用户知道“下一步做什么、还缺什么” |

## 模式串联规则

- “整理并出题”：先执行授课逻辑复习文档，再用已建立的证据块生成测验。
- “分析错题并计划复习”：先生成真题陷阱卡，再登记错题并安排复习节点。
- “根据考纲划重点”：先建立考点雷达，再用真题分值或重复次数校正优先级。
- “考考我/高压自测”：进入 Grill-Me 状态机，按 `ASK_ONE → 动态追问 → AUDIT` 逐题推进。
- “开始复习/资料体检”：先生成资料可用性、复习准备度与学习地图，再由用户选择整理、测验或自测。

## 失败保护

- 页码无法识别：`[资料缺失：当前解析结果无法定位原始页码，建议重新上传带页码文件]`。
- 图片型公式无法解析：`[资料缺失：第 N 页公式关键符号无法辨认，建议上传清晰页面]`。
- 题型、分值或考试范围未提供：使用“建议值”或 `资料缺失`。
- 草稿出现术语白名单外的专业项：删除扩写并输出具体的资料缺失提示。
- 推导需要资料外定理或隐藏条件：停止推导并指出缺少的依赖。
- 多份材料互相矛盾：并列保留原文与来源，暂停受影响推导和命题，等待用户指定课程口径。
- 交付前审计出现未覆盖结论、未闭合推导或未处理越界术语：不得宣告完成，先修正或列明未完成项。
