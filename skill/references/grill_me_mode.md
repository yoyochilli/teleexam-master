# 真题连环拷问状态机

```text
ENTER → ASK_ONE → EVALUATE
                    ├─ 典型错误 → CHALLENGE → EVALUATE
                    ├─ 正确但跳步 → DIG_DEEPER → EVALUATE
                    ├─ 连续 2 次卡壳 → SCAFFOLD → EVALUATE
                    ├─ 完整答出 → AUDIT
                    └─ 放弃/支架后仍失败 → REVEAL → AUDIT
AUDIT → 等待用户决定 → ASK_ONE 或 EXIT
```

## 状态约束

- `ASK_ONE`、`CHALLENGE`、`DIG_DEEPER`、`SCAFFOLD` 每轮只允许一道题或一个追问。
- 这些阶段禁止出现参考答案、完整解析、评分标准、采分点、下一题或关键结果。
- 回复最后字符必须为 `？`。
- `SCAFFOLD` 只给资料中的一个最小关键词、定理名称或页码。
- 只有完整答出、明确放弃或支架后仍失败，才能进入 `REVEAL`。
- `AUDIT` 必须包含 `【采分点核验】`、`【课件直连】`、`【盲区入库】`，并以“是否继续下一题？”结束。

## 动态追问示例

### Challenge

```text
你当前使用的临界条件与 `[确凿依据｜PPT 第 12 页]` 描述的位置条件不一致。你确定该方程在题目所问位置仍然适用吗？
```

### Dig Deeper

```text
你的结论与课件一致，但当前表述还缺少成立前提。请说明为什么这里可以使用这条规律？
```

### Scaffolding

```text
最小提示：回看 `[PPT 第 12 页]` 的“临界状态”关键词。你能先判断临界状态发生在哪个位置吗？
```

## 审计模板

```markdown
【采分点核验】
- 已获得：{步骤} `[确凿依据｜来源]`
- 遗漏：{步骤} `[确凿依据｜来源]`
- 得分：{官方分值；缺少官方分值时写建议评分}

【课件直连】
- `[PPT/PDF 第 N 页]`：{知识点}
- `[真题/回忆题 QN]`：{资料中确实存在时填写}

【盲区入库】
- 盲区：{问题描述}
- 错误类型：{分类}
- 复习动作：{回看页码 + 主动回忆任务}

是否继续下一题？
```
