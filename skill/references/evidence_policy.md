# 证据边界与防幻觉协议

本协议适用于所有课程事实、公式、答案、评分点、考点优先级和复习建议。

## 1. 术语白名单

处理资料前建立 `课程术语表`，来源仅限用户上传的课件、笔记、考纲与题目。记录术语原文、首次出现位置、符号写法和上下文。

- 输出课程解释时，只能使用术语表中的专业名词。
- 普通连接词可用于整理语句，但不得承载新增课程事实。
- 用户问题里出现、资料里未出现的专业词可在缺失提示中原样复述，不得扩写定义、背景或公式。
- 同义词替换可能改变课程口径时，保留资料原词。

## 2. 三级置信度判定器

每条课程事实只选择一个状态。

### `[确凿依据]`

适用于资料正文、题目或考纲明确出现，且输出仅做引用、等义压缩或格式整理的内容。

```text
[确凿依据｜PPT 第 5 页] 过程特性描述不同功能事件的出现顺序。
```

### `[逻辑推导]`

必须同时满足：每个前提都有确凿依据；只使用资料中已有公式、规则或基础代数变形；没有新定理、新术语、隐藏条件或外部数值；列出全部依赖，读者可以复算。

```text
[逻辑推导｜依赖：PPT 第 23 页] 当 B = 4 kHz 时，最高码元速率为 8 kBaud；由 2B 代入得到。
```

任一条件不满足时降级为 `[资料缺失]`。

### `[资料缺失]`

适用于资料未覆盖、页码无法定位、公式符号模糊、答案需要外部知识、推导依赖未给出的定理、专业术语不在白名单或资料存在冲突的情况。

```text
[资料缺失：上传课件中未见 XX 的证明，建议核对教材或补充对应章节]
```

## 3. 外部知识熔断

1. 扫描草稿中的专业名词和符号。
2. 对照课程术语表逐项匹配。
3. 检查每个结论的来源标签或推导依赖。
4. 任一专业项无法匹配时，删除相关扩写并生成 `[资料缺失：...]`。

课件仅给出麦克斯韦方程组积分形式时，`散度`、`旋度`、`\nabla` 和微分形式均在白名单之外。输出只能保留积分形式；用户追问时返回：

```text
[资料缺失：上传课件中未见麦克斯韦方程组微分形式及相关算子，建议核对教材或补充资料]
```

## 4. 公式保真检查

逐项检查变量大小写，标量、向量或矩阵记法，上下标，指数，积分上下限，系数，正负号，单位和适用条件。

资料明确为向量时沿用 `\vec{E}` 或 `\mathbf{E}`，全文保持一致。资料没有标明向量属性时，不自行加粗或加箭头。关键字符模糊时停止转写完整公式：

```text
[资料缺失：PDF 第 18 页公式的积分上限无法辨认，建议上传清晰页面]
```

## 5. 交付前审计

- 所有课程事实均带三级置信度之一。
- 所有确凿依据均有精准来源。
- 所有逻辑推导均列出依赖且依赖闭合。
- 所有资料外专业项均已熔断。
- 所有公式完成符号级核对。
- 所有资料缺失提示均说明缺口和补救动作。
