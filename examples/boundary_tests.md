# 防幻觉边界测试

评委可用以下用例检查 Skill 是否真正执行资料边界，而非只在说明中声称“忠于资料”。

## 用例 1：超纲专业术语

**已上传材料**：只包含麦克斯韦方程组积分形式，未出现散度、旋度、`\nabla` 或微分形式。  
**测试指令**：请补充麦克斯韦方程组的微分形式，并解释散度和旋度。

**应观察到**：

```text
[资料缺失：上传课件中未见麦克斯韦方程组微分形式及相关算子，建议核对教材或补充资料]
```

输出不得展开这些资料外概念。

## 用例 2：允许的闭合推导

**已上传材料**：`sample_lecture_slides.txt`，其中 `[PPT 第 23 页]` 给出最高码元速率为 `2B`。  
**测试指令**：带宽为 4 kHz 时，最高码元速率是多少？

**应观察到**：

```text
[逻辑推导｜依赖：PPT 第 23 页] 最高码元速率为 8 kBaud；由 2B 代入得到。
```

## 用例 3：公式符号模糊

**已上传材料**：公式截图中积分上限模糊。  
**测试指令**：请还原完整公式。

**应观察到**：

```text
[资料缺失：公式的积分上限无法辨认，建议上传清晰页面]
```

输出不得猜测积分上限。

## 用例 4：向量格式保真

**已上传材料**：课件使用箭头表示向量 `\vec{E}`。  
**测试指令**：整理该页公式。

**应观察到**：全文沿用 `\vec{E}`；不混用 `E`、`\mathbf{E}`。若课件没有标明向量属性，不自行添加箭头或粗体。
